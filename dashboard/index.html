Token launch radar

Every protocol with no token yet, ranked by what its launch would be worth.

Launch Radar reads one sealed snapshot of the protocol universe, finds every protocol that records no token, and prices each one against the protocols that already launched in its own line of business: what the market pays per dollar of TVL there, adjusted for momentum, reach and track record. One cut comes first: bridges are set aside, never priced — a bridge's TVL is other protocols' assets in custody, not a launch waiting to happen. Each row carries the working and a six-step plan to farm it. Implied value is a model, not a promise — and never a prediction that a token will exist.

How implied value is computed

A protocol with no token has no price, but the snapshot is full of protocols that did launch. For each of those, market cap divided by TVL is what the market actually paid per dollar of TVL. The radar takes the median of that ratio inside each category — every ratio first winsorised to [0.01, 4] so one micro-cap cannot bend a category — then shrinks it toward the global median as if the global figure had six extra peers, and caps the result at 3. A category with no launched peers prices at the global median. That multiple is the model's whole claim about a line of business: exchanges, whose TVL is largely other people's assets in transit, carry the market's own low multiples; curators and exchanges of risk carry higher ones. One category rule stands in front of the pricing: a protocol filed as a Bridge or a Canonical Bridge is never ranked, however large its TVL — its set-aside is stated below, with the protocols it names.

implied = round( tvl_usd × category_multiple × momentum × breadth × track_record )
  • Momentum — 1 + clamp(change_7d, −50, +60) / 100 × 0.6. A protocol gathering TVL is gathering the users a launch rewards; one bleeding TVL is discounted, never below ×0.70 or above ×1.36.
  • Breadth — 1 + 0.04 × log2(chains). Each doubling of the chain count is another community a token would drop to.
  • Track record — 0.85 rising to 1.15 over four years since DefiLlama first listed the protocol. Years at scale with no token is evidence of staying power and of an unrewarded user base; a protocol listed last month is discounted instead. An unlisted age scores a neutral 1.00.

Every factor is rounded to four decimals before the multiplication, so each row's implied value is exactly reproducible from the factors printed beside it — the detail view recomputes it in this page, from the row's own numbers, and shows the same dollar the board carries. No protocol name is special-cased anywhere in the model: one function prices every row.

Bridges and canonical bridges — set aside, not ranked

A bridge's TVL is other protocols' assets in custody or in transit, not a product of its own waiting to launch: WBTC is Bitcoin in a custodian's hands, and no wrap of an asset that already trades becomes a launch candidate by growing. The snapshot's own watchlist excludes both bridge categories for the same reason, so the board does too — a protocol DefiLlama files as a Bridge or a Canonical Bridge is set aside before pricing, whatever its size.

What this model cannot see

  • The snapshot carries no parent-protocol field, so a wrapped product outside the bridge categories is caught only by the name tests (a version suffix, a whole word wrapped / staked / staking, an exchange's name at the front) — the same tests the snapshot's own watchlist documents, applied without its $50M floor. One filed under another category, with a clean name, would slip through.
  • Peer value is circulating market cap, not fully diluted value; a launch priced on full supply would read higher.
  • TVL is one day's figure and seven days of momentum is a short window; the model prices the record as it stands, nothing more.
  • Say a protocol records no token, never that it has none: a token its DefiLlama record does not carry would not appear here.
